# Translating the New Testament into Malayalam — instructions for every translator

You are making the "AI translation" of a Malayalam Catholic Bible reading app. Readers will compare
it with Malayalam Catholic (POC) Bibles, so it must be faithful, natural and dignified. Matthew and
Mark are already done; every book must read like the same translation.

## Source and style
- Translate **from the Greek text** (the standard critical text, Nestle–Aland / UBS), which you know.
  Render what the Greek says — faithfully and completely — in natural, dignified modern Malayalam
  that reads well aloud in church. Do not paraphrase, explain, add words the Greek doesn't imply, or
  copy the wording of an existing Malayalam translation.
- **Do not open or copy anything from the app repository** (D:\Sunil\Bible). Work only from your
  knowledge of the Greek text.
- Letters (Paul and the others): keep the argument's logic visible (γάρ → എന്തെന്നാൽ / കാരണം,
  οὖν → ആകയാൽ / അതിനാൽ, ἀλλά → എന്നാൽ / മറിച്ച്); long Greek periods may be split into several
  Malayalam sentences **inside the same verse**. Greetings and blessings in liturgical Malayalam.
- Poetry and hymns (Lk 1:46–55, 1:68–79, 2:29–32; Phil 2:6–11; Col 1:15–20; Revelation's songs):
  dignified, rhythmic Malayalam, still one entry per verse, no line breaks inside a verse.

## Conventions shared with Matthew and Mark (must match)
- **Jesus in narrative: അവൻ** and its case forms (അവന്റെ, അവനെ, അവനോട്, അവന്); യേശു where the
  Greek names him. People speaking **to** Jesus: അങ്ങ് / അങ്ങയുടെ; opponents and demons may use
  നീ. **God** in the third person: അവിടുന്ന് / അവിടുത്തെ. In the letters, Christ in the third
  person: അവൻ / ക്രിസ്തു as the Greek has it.
- "ἀμὴν (ἀμὴν) λέγω ὑμῖν" → "സത്യമായി (സത്യമായി) ഞാൻ നിങ്ങളോടു പറയുന്നു".
- κύριος for a human master / owner → യജമാനൻ / ഉടമസ്ഥൻ; for the Lord → കർത്താവ്.
- Speech in “ ”, quotes inside speech in ‘ ’. A speech running over several verses opens in its
  first verse and closes in its last.
- Fixed terms: θεός → ദൈവം; κύριος → കർത്താവ്; ὁ πατήρ (God) → പിതാവ്; πνεῦμα ἅγιον →

  ὁ υἱὸς τοῦ ἀνθρώπου → മനുഷ്യപുത്രൻ; Χριστός → ക്രിസ്തു; Ἰησοῦς Χριστός → യേശുക്രിസ്തു;
  ὁ λόγος (Jn 1) → വചനം; ἀμνὸς τοῦ θεοῦ → ദൈവത്തിന്റെ കുഞ്ഞാട്; ἀρνίον (Revelation) → കുഞ്ഞാട്;
  εὐαγγέλιον → സുവിശേഷം; ἐκκλησία → സഭ; ἀπόστολος → അപ്പസ്തോലൻ; μαθηταί → ശിഷ്യന്മാർ;
  οἱ δώδεκα → പന്ത്രണ്ടുപേർ; ἅγιοι (believers) → വിശുദ്ധർ; ἀδελφοί → സഹോദരരേ / സഹോദരന്മാർ;

## Verse numbering
- Give **exactly one entry for every verse number you are given**, in order, with only that verse's
  text. Never merge or split verses, never skip one. Numbering is that of English Catholic Bibles
  (RSV-CE). If the count you were given does not fit the text you know, do not invent or merge —
  say so in your reply.
- Verses that the critical text omits but Catholic Bibles number (**Lk 17:36, 23:17; Jn 5:4;
  Acts 8:37, 15:34, 24:7, 28:29; Rom 16:24**): translate the traditional text and put the whole
  verse in square brackets [ … ], so the numbering stays complete.
- **Translate without brackets** (canonical for Catholics): Lk 22:43–44, Jn 7:53–8:11.
  1 Jn 5:7–8 **without** the later "three witnesses in heaven" addition.

## Section headings
- `heading` is a short Malayalam section heading printed **before** that verse where a new section
  starts, as printed Bibles have them. Use them sparingly — usually 1 to 5 per chapter, normally one
  on verse 1 — and `""` elsewhere.

## Output: one JSON file per chapter
Write with the Write tool to `<OUTDIR>/<BOOK>_<chapter>.json` (UTF-8), where BOOK is the code you
were given (e.g. LUK, JHN, ACT, ROM, 1CO, 2CO, GAL, EPH, PHP, COL, 1TH, 2TH, 1TI, 2TI, TIT, PHM, HEB,
JAS, 1PE, 2PE, 1JN, 2JN, 3JN, JUD, REV), exactly this shape:

```json
{
  "book": "LUK",
  "chapter": 1,
  "verses": [
    { "v": 1, "heading": "ആമുഖം", "text": "..." },
    { "v": 2, "heading": "", "text": "..." }
  ]
}
```

- Valid JSON: inside `text` / `heading`, do **not** use straight double quotes `"` — for speech use
  “ ” (and ‘ ’ inside them). No line breaks inside a string.
- Then validate every file you wrote: `node <OUTDIR>/check.cjs <BOOK>_<chapter>.json ...`
  It must print `OK` for each file. Fix and re-check anything it reports. (If the Bash tool fails,
  run it with PowerShell.)
