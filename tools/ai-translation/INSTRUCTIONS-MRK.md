# Translating the Gospel of Mark into Malayalam — instructions for every translator

You are making the "AI translation" of a Malayalam Catholic Bible reading app. Readers will compare
it with Malayalam Catholic (POC) Bibles, so it must be faithful, natural and dignified. Matthew is
already done; Mark must read like the same translation.

## Source and style
- Translate **from the Greek text of Mark** (the standard critical text, Nestle–Aland / UBS), which
  you know. Render what the Greek says — faithfully and completely — in natural, dignified modern
  Malayalam that reads well aloud in church. Do not paraphrase, explain, add words the Greek
  doesn't imply, or copy the wording of an existing Malayalam translation.
- **Do not open or copy anything from the app repository** (D:\Sunil\Bible). Work only from your
  knowledge of the Greek text.
- Mark's vivid style (καὶ εὐθύς "immediately", historic presents) may be smoothed into natural
  Malayalam narrative, but keep "ഉടനെ" where εὐθύς carries meaning.
- Aramaic words Mark quotes, then explains: keep the Aramaic in Malayalam letters followed by the
  meaning, as Mark does — ബൊവനെർഗെസ് (3:17), തലീത്താ കൂം (5:41), കൊർബാൻ (7:11), എഫ്ഫാത്താ (7:34),
  അബ്ബാ (14:36), ഏലോയി, ഏലോയി, ലാമാ സബക്താനി (15:34), ഗൊൽഗോഥാ (15:22).

## The same conventions as Matthew (must match)
- **Jesus in narrative: അവൻ** and its case forms (അവന്റെ, അവനെ, അവനോട്, അവന്). യേശു where the
  Greek names him. People speaking **to** Jesus: അങ്ങ് / അങ്ങയുടെ (disciples, the sick, the
  respectful); opponents and demons may use നീ. **God** in the third person: അവിടുന്ന് / അവിടുത്തെ.
- "ἀμὴν λέγω ὑμῖν" → "സത്യമായി ഞാൻ നിങ്ങളോടു പറയുന്നു".
- κύριος for a human master / owner in parables → യജമാനൻ / ഉടമസ്ഥൻ; for the Lord → കർത്താവ്.
- Speech in “ ”, quotes inside speech in ‘ ’. A speech running over several verses opens in its
  first verse and closes in its last.
- Fixed terms: θεός → ദൈവം; κύριος → കർത്താവ്; ὁ πατήρ (God) → പിതാവ്; πνεῦμα ἅγιον →
  പരിശുദ്ധാത്മാവ്; βασιλεία τοῦ θεοῦ → ദൈവരാജ്യം; ὁ υἱὸς τοῦ ἀνθρώπου → മനുഷ്യപുത്രൻ;
  Χριστός → ക്രിസ്തു; εὐαγγέλιον → സുവിശേഷം; μαθηταί → ശിഷ്യന്മാർ; οἱ δώδεκα → പന്ത്രണ്ടുപേർ;
  ἀπόστολοι → അപ്പസ്തോലന്മാർ; Φαρισαῖοι → ഫരിസേയർ; Σαδδουκαῖοι → സദുക്കായർ; Ἡρῳδιανοί →
  ഹേറോദേസ്പക്ഷക്കാർ; γραμματεῖς → നിയമജ്ഞർ; ἀρχιερεῖς → പ്രധാനപുരോഹിതന്മാർ; πρεσβύτεροι →
  ജനപ്രമാണികൾ; τελῶναι → ചുങ്കക്കാർ; συναγωγή → സിനഗോഗ്; ἱερόν → ദേവാലയം; σάββατον → സാബത്ത്;
  μετανοεῖτε → മാനസാന്തരപ്പെടുവിൻ; βάπτισμα / βαπτίζω → സ്നാനം / സ്നാനം നൽകുക (John's),
  ജ്ഞാനസ്നാനം in 16:16; δαιμόνιον → പിശാച് (pl. പിശാചുക്കൾ); πνεῦμα ἀκάθαρτον → അശുദ്ധാത്മാവ്;
  Σατανᾶς → സാത്താൻ; γέεννα → നരകം; δηνάριον → ദനാറ; Καῖσαρ → സീസർ; ὡσαννά → ഹോസാന;
  παραδίδωμι (Judas) → ഒറ്റിക്കൊടുക്കുക; χαῖρε → സ്വസ്തി.
- Proper names — exactly these spellings (as in Matthew):
  യേശു, മറിയം, ജോസഫ്, സ്നാപകയോഹന്നാൻ, ശിമയോൻ, പത്രോസ്, അന്ത്രയോസ്, യാക്കോബ്, യോഹന്നാൻ, സെബദി,
  പീലിപ്പോസ്, ബർത്തലോമിയോ, മത്തായി, തോമസ്, അൽഫേയൂസ്, തദേവൂസ്, കനാനേയനായ ശിമയോൻ, യൂദാസ് സ്കറിയോത്താ,
  ലേവി, ഹേറോദേസ്, ഹേറോദിയാ, പീലിപ്പോസ് (Herod's brother), പീലാത്തോസ്, ബറാബ്ബാസ്, ഏലിയാ, ഏശയ്യാ,
  മോശ, ദാവീദ്, അബ്രാഹം, ഇസഹാക്ക്, യാക്കോബ്, ബേൽസെബൂൽ, യായ്റോസ് (Jairus), ബർതിമേയൂസ്,
  മഗ്ദലേന മറിയം, സലോമി, കിറേനേക്കാരനായ ശിമയോൻ, അലക്സാണ്ടർ, റൂഫോസ്, അരിമത്തെയാക്കാരനായ ജോസഫ്,
  ലെഗിയോൻ (5:9);
  places: ഗലീലി, ഗലീലിക്കടൽ, യൂദയാ, ജറുസലേം, ജോർദാൻ, നസറത്ത്, കഫർണാം, ഇദുമെയാ, ടയിർ, സീദോൻ,
  ഗെരസേനർ (5:1), ദെക്കാപ്പോളിസ്, ഗനേസറത്ത്, ബേത്‌സയ്ദാ, ദൽമനൂത്താ, കേസറിയാ ഫിലിപ്പി, ജറീക്കോ,
  ബേത്ഫഗെ, ബഥാനിയാ, ഒലിവുമല, ഗത്‌സെമനി, ഗൊൽഗോഥാ.
  For names not in the list, use the usual Malayalam Catholic (POC) form, consistently.

## Verse numbering
- Give **exactly one entry for every verse number you are given**, in order, with only that verse's
  text. Never merge or split verses, never skip one.
- Verses that the critical text omits but Catholic Bibles number (**Mk 7:16, 9:44, 9:46, 11:26,
  15:28**): translate the traditional text and put the whole verse in square brackets [ … ], so the
  numbering stays complete.
- **16:9–20 (the longer ending) is canonical for Catholics: translate it in full, without brackets**
  (a heading on 16:9 is fine). Do not add the "shorter ending".

## Section headings
- `heading` is a short Malayalam section heading printed **before** that verse where a new section
  starts, as printed Bibles have them. Use them sparingly — usually 1 to 5 per chapter, normally one
  on verse 1 — and `""` elsewhere.

## Output: one JSON file per chapter
Write with the Write tool to `<OUTDIR>/MRK_<chapter>.json` (UTF-8), exactly this shape:

```json
{
  "book": "MRK",
  "chapter": 1,
  "verses": [
    { "v": 1, "heading": "സ്നാപകയോഹന്നാന്റെ പ്രസംഗം", "text": "..." },
    { "v": 2, "heading": "", "text": "..." }
  ]
}
```

- Valid JSON: inside `text` / `heading`, do **not** use straight double quotes `"` — for speech use
  “ ” (and ‘ ’ inside them). No line breaks inside a string.
- Then validate every file you wrote: `node <OUTDIR>/check.cjs MRK_<chapter>.json ...`
  It must print `OK` for each file. Fix and re-check anything it reports. (If the Bash tool fails,
  run it with PowerShell.)
